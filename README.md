# Ethical Hacking Study Lab

A standalone static study website for the supplied Ethical Hacking Lectures 1-4 guide. Includes all four lecture chapters, original diagrams and tables, the night-before field sheet, and 63 active-recall questions with local progress tracking.

The site is generated from source in a single self-contained HTML file so GitHub Pages can serve it without a build pipeline. To edit the content or styling, use the source project and run `npm install && npm run build`, then copy `dist/index.html` to this repository.

Only study and test systems you own or are explicitly authorized to assess.
